# شحنات المحل — mart-shipments

تطبيق ويب بسيط لاستلام الشحنات في سوبر ماركت بفرعين. الموظف يمسح الباركود بالكاميرا
من موبايله ويسجّل الكميات، والمدير يشوف كل الشحنات ويعدّلها ويحمّلها Excel أو TXT
ويدير ملف الأصناف. بيشتغل من غير إنترنت وبيزامن أول ما النت يرجع، وكل حاجة مجانية.

## الروابط

| | الرابط | الرقم السري |
|---|---|---|
| الموظفين | https://mohamedroshdi.github.io/mart-shipments/ | رقم الفرع عند أول تشغيل |
| المدير | https://mohamedroshdi.github.io/mart-shipments/manager.html | `1994` لكل الفروع |
| النظام (الأدمن) | https://mohamedroshdi.github.io/mart-shipments/admin.html | `7007` |

الفروع: **فرع قويسنا** (`1010`) و **فرع شبين الكوم** (`2020`). الرقم بيستخدمه الموظف
لاختيار فرعه، وبيستخدمه مدير الفرع للدخول على شحنات فرعه بس.

الفروع والأرقام وأنواع الشحنات كلها بتتعدّل من **صفحة النظام** على طول، والموبايلات
بتشوف التعديل مع أول فتح. ملف `firebase-config.js` بقى الأساس اللي بيشتغل عليه
التطبيق لو مفيش إعدادات محفوظة — ورقم الأدمن المكتوب فيه بيفضل شغال دايمًا كصمام أمان.

## إزاي بيشتغل

1. الموظف يفتح الرابط، يكتب اسمه، يختار الفرع ويكتب رقمه — مرة واحدة على الموبايل.
2. «إضافة إلى الشاشة الرئيسية» تحوّله لتطبيق بأيقونة على الموبايل.
3. شحنة جديدة → نوع الشحنة (إذن استلام / إذن مرتجع / تحويل فرع) → اسم الشحنة →
   مسح الباركودات بالكاميرا أو كتابتها.
4. اسم الصنف بيظهر لوحده من ملف الأصناف. الباركود اللي مش في الملف **مش هيتسجّل**،
   وبتظهر رسالة توضّح السبب مع زرار لنسخ الباركود وإرساله للمدير.
5. المدير يشوف كل الشحنات مفلترة بالفرع والنوع، يعدّل الكميات، يحذف أصناف، ينسخ
   الشحنة (باركود + كمية) أو يحمّلها Excel / TXT، ويدير ملف الأصناف من زرار «الأصناف».
6. تحميل كل الشحنات مرة واحدة بزرار **ZIP بالمجلدات**: ملف مضغوط جواه مجلد لكل نوع
   شحنة، وجوه كل مجلد الشحنة في ملف Excel وملف TXT.
7. الأدمن من صفحة النظام: يضيف فرع أو نوع شحنة، يغيّر أي رقم سري، يشوف «آخر العمليات»
   (مين حذف أو عدّل إيه وامتى)، ويحذف شحنات بالجملة أو يمسح ملف الأصناف.

خطوات الإعداد الكاملة لصاحب المحل بالعربي في [SETUP.md](SETUP.md).

## للمطوّر

HTML/CSS/JS خام — مفيش framework ولا build. Firebase Firestore للبيانات،
GitHub Pages للاستضافة، Playwright للاختبارات.

```bash
npm install
npx playwright test          # 27 اختبار
python3 -m http.server 8080  # ثم افتح http://localhost:8080/?test=1
```

`?test=1` يشغّل التطبيق على localStorage بدل Firestore، فالاختبارات لا تلمس البيانات
الحقيقية. النشر = push على master. قواعد الحماية تُنشر بأمر منفصل.

تفاصيل المعمارية والقواعد والفخاخ المعروفة في [CLAUDE.md](CLAUDE.md).
التصميم والخطة الأصلية في `docs/superpowers/`.
